# Platforms, topology and costs

Refreshed 2026-10-20 from the official sources linked in each row. Prices are USD, before taxes and account-specific contracts. This is a research snapshot, not a price guarantee or a deployment test. Refresh pricing at each provider's implementation gate and before release.

## Topology

Layer A delegates transformations to a configured image provider. Layer B is an image origin/service that should sit behind an actual CDN. Layer C publishes immutable build artifacts to storage with a public delivery base. These may be combined; the npm package includes no global distribution network, storage subscription, or third-party usage allowance.

Recommended flows:

- Managed: browser → provider CDN/optimizer → approved source origin.
- Self-hosted: browser → CDN → Imageway Node/Bun service → approved source origin.
- Worker: browser → Worker/cache → Images binding or transformation service → approved origin/R2.
- Static: browser → CDN/storage → prebuilt content-addressed artifact; no runtime transformation.

The service is not automatically an SSRF-safe network boundary merely because it is at the edge. A restricted object-key source is the preferred Worker mode.

## Cloudflare limits affecting design

The current [Images limits](https://developers.cloudflare.com/images/get-started/limits/) distinguish remote sources (100MB) from hosted uploads (10MB) and binding input (20MB). They also list 100MP image area limits, stricter animation handling, and an AVIF dimension limit of 1,200px. Model these as backend capabilities; do not promise all requested widths will produce AVIF. Local `wrangler dev` success would not establish production feature parity.

[Workers limits](https://developers.cloudflare.com/workers/platform/limits/): 128MB per isolate, Free CPU 10ms/request and 100K requests/day, Paid CPU configurable up to five minutes with a lower default. Therefore a general-purpose AVIF WASM fallback is an experiment, not the default encoding plan. Stream bounded inputs; limit concurrent jobs. Cache API and `waitUntil` semantics must be tested independently. R2 is durable object storage, not a guarantee of globally warmed transformation caches.

A cost estimator should accept source count, permitted widths, crops, formats, bytes, requests, hit rate, refresh rate and retention. A bounded transform space constrains compute but does not prevent delivery, attack traffic or log charges. A distributed budget guard requires shared counters and provider/account limits; per-isolate counters are insufficient.

## Negotiated cache configuration

Explicit format URLs are the default and require the whole canonical image query in the CDN cache key. Never ignore source/width/format parameters.

| CDN                                                                                                             | Negotiated mode policy                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Cloudflare](https://developers.cloudflare.com/cache/advanced-configuration/vary-for-images/)                   | Native Vary for Images is plan-gated (Pro/Business/Enterprise), configured for variants and extension-bearing paths. It does not automatically apply to an arbitrary `/_img` endpoint. For that endpoint, a Worker can negotiate into a canonical explicit-format internal cache URL            |
| Fastly                                                                                                          | Prefer explicit format. Honor origin Vary and forward Accept plus Save-Data in service configuration, or negotiate at Compute into an explicit-format cache key. Imageway does not generate account-specific VCL; validate an AVIF/WebP/JPEG pair in staging before enabling negotiated caching |
| Bunny                                                                                                           | Prefer explicit format or the optimizer's documented negotiation. Do not claim arbitrary origin Vary behavior; use explicit Imageway format URLs and include the entire query in the Pull Zone cache key; native optimizer automatic format varies by its own product policy                    |
| [CloudFront](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/controlling-the-cache-key.html) | Include required query fields in cache policy. For negotiated mode, normalize format at the edge into a bounded key; forwarding Accept to the origin without including the normalized variant in cache identity is unsafe                                                                       |

Raw `Accept`, DPR, Width and Save-Data must not multiply unbounded variants. The service can retain HTTP `Vary: Accept` for downstream correctness while internally storing by negotiated format. A mutable remote URL does not become immutable simply because the request is signed.

## Evidence and release policy

No cloud credentials, paid service activation, production infrastructure creation or cloud deployment was performed. Local random tokens protect emulator admin routes. Native provider URLs use conformance tests; Cloudinary demo delivery, Wrangler bindings and Docker were executed. Storage SDK targets remain type-checked/local-target-tested without a paid staging upload. Account bills require the selected workload, subscription, region and contract.

## Workload model and practical free-tier controls

Estimate requests and bytes separately from transformations. At 1 million deliveries averaging 40 KB, image payload alone is about 40 GB (decimal), before page assets/logs/headers. At 99% CDN hit rate, about 10,000 origin requests remain; that is not necessarily 10,000 unique transformations. Cloudflare explicitly excludes format and quality from its monthly uniqueness meter; dimensions/crops/DPR/source changes still matter. Imageway's shared budget counts admitted encoder calls, conservatively, rather than promising an exact vendor bill.

For example, 500 originals × 5 physical sizes = 2,500 basic Cloudflare transform combinations if other counted parameters stay fixed, below its 5,000 included tier. Format/quality variants can increase stored bytes/cache traffic without increasing that specific uniqueness meter. Hosted Images storage/delivery, R2 operations, Worker CPU/requests and Durable Object operations are separate. Use broad stable purge tags/prefixes, immutable build variants, bounded widths, and provider billing alerts. Keep the Worker monthly admission guard below the allowance if that conservative model fits your use case. A paid account may have other applications sharing the allowance.

Netlify's free 300 credits would cover only about 15 GB of bandwidth if no credits were consumed by deploys/requests/compute; real workloads have those other meters. Do not describe that as a free 15 GB image entitlement. Supabase image transformations require Pro or above (from $25/month), independently of storage/egress allowance. Keep auto-recharge/spend caps at the account's intended setting; this package does not toggle billing.

Imageway emits no Accept-CH header. DPR is an explicit bounded URL parameter; arbitrary viewport hints should not enter a CDN key. For signed public URLs, honor the clamped max-age/must-revalidate and never serve stale past expiry. Purge the external CDN separately from the origin generation API. For private signed originals, keep downstream caching private/no-store.
