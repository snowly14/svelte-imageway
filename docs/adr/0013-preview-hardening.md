# Preview hardening after the local audit

Status: accepted, 2026-10-20.

Before first public distribution, fix the five reproduced audit findings. Worker response deadlines must not release native transform admission until the underlying promise settles. Node artifact cache identities include the full non-provider processing configuration so stricter limits cannot reuse an earlier representation. Background base and responsive declarations share the same stylesheet cascade; explicit user inline styles retain their normal precedence.

Memory caches reject empty buffers and cap entries at 4,096 as well as their byte budget. Disk caches share a weakly held per-directory index between processors, serialize mutations, bound metadata reads to eight, and reconcile external writers every 30 seconds. Same-process writes are accounted immediately; independent processes may temporarily exceed the combined disk budget until reconciliation. Use a single writer process for a strict shared budget. Initial indexing is O(n log n); ordinary writes no longer scan all entries.

Regression coverage exercises slow encoders after deadline, tightened output policy, empty/tiny cache entries, concurrent disk writers and external reconciliation, and responsive background changes in a real browser. The 0.1 preview retains the previously documented 1.0 size and benchmark limitations.
